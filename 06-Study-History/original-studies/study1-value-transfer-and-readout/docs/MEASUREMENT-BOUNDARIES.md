# How to interpret the measurements

**An intervention success is an output equality.** The final parsed integer must equal the exact oracle g_r(z_d). This does not uniquely identify a literal register. Full-expression transfer always predicts the same result in this task. In the complete development set, additional counterfactual collisions occur with first-operand copying in six pairs, second-operand copying in three, and donor-operation predictions in two. All prediction matches are retained. These counts can overlap.

**The primary denominator includes every planned pair.** A missing semantic position is counted as unsuccessful and invalid/unavailable. An invalid output generated after a runnable intervention is a different event. Aggregate tables separate unavailable positions, generated parser failures and truncation. Truncations can also be parser failures; those columns are not disjoint categories.

**The selected pre_z site is a late output site.** Both original arithmetic results are already present in all 40 discovery thinking traces. The names pre_z/post_z refer to the labelled final response, not to the first existence of an internal value. The earlier equation locator is an additional textual timing diagnostic and can miss expressions written in other forms.

**Only one historical activation is replaced.** All 1024 dimensions of one native block output are replaced. Cached execution writes at prefix construction, removes the hook, then generates freely. Reference no-cache execution applies the same intervention at that same historical position during each recomputation. Neither intervention repeatedly steers new output positions. The line-clamp experiment extends the prefix beyond the writable node but retains its original position.

**A numeric prefix can grow.** The tokenizer represents the inspected ASCII integers 0–199 as one token per digit. A prefix ending in 5 can continue with a new 2 to print 52. The amendment-004 text assay allows this; the amendment-006 assay includes the original line ending to fix a completed numeral. Never describe the open-prefix assay as clamping the full printed value.

**Sampling is reproducible but not averaged across seeds.** Each prompt has one deterministic prompt-derived sampling seed. Replaying prior tokens advances the sampling stream by the replay length; identity replay was validated. Different prefix lengths advance the stream differently and consume different portions of the 512-token total allowance. No multi-seed robustness claim is made.

**Batching is validated, not a new intervention.** Left padding and unpadded position IDs preserve recipient positions. Mixed-layer and additive operators were checked against serial execution. In batch records, `other_positions_max_change=0` is recorded from the explicit write-by-index construction; the serial positive-control hook measured untouched-position differences directly. Primary conclusions do not rely on treating the batch field as an independently scanned tensor statistic.

**Controls have more than one relevant prediction.** A random or mismatched donor can correctly transfer its own value while missing the originally designated donor target. Both rates are reported. A donor pre-final state can carry a generic upcoming number, so g_r(y_d) is scored separately. Copying donor y as the final output and using donor y as a new intermediate are different outcomes.

**The data are paired and clustered.** The initial 20 pairs contain four donor-value clusters, all with single-digit z. The full 100 contain 20 donor values, 20 recipient values, 12 arithmetic structures and 100 distinct complete recipient programs. Two templates per split are fixed conditions. One-axis cluster bootstrap envelopes are sensitivity descriptions, not exact multiway or selection-adjusted confidence intervals. An all-zero bootstrap difference can yield a point interval without proving equivalence or the absence of rare effects.

**Draft-language competence is a separate supplement.** English, Spanish and Tamil share numerical problems and output labels. Spanish/Tamil wording is [redacted]-reviewed and still lacks independent fluent review. Thinking language is unconstrained. Language family, script, prompt length, wording and unknown training exposure are not experimentally separated. Baseline errors or failed cross-language patches without reliable within-language effects would not establish a language barrier.

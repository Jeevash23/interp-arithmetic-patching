# Supplement: the donor model's actual first output token

2 October 2026, before selected-site fresh control outcomes. One of the 12 donor problems is answered incorrectly in the selected format, accounting for three paired records. The original frozen text control forces the first digit of the mathematically correct donor answer. For those three records, that need not equal the model's actual first donor output token.

Retain the original ten conditions and their analysis unchanged. Add a supplementary text control that forces only the actual first output token recorded in the donor baseline, then performs otherwise unpatched fresh recipient generation. All baseline donor outputs are strict integers; verify that the first token is their first numeral token. This tests the strongest directly observed first-token alternative without silently dropping donor failures.

Where the forced token equals the original textual control, reuse its exact saved generation and mark that reuse. Where it differs, generate afresh. Because this is a text-only control, identical recipient-prompt/forced-token conditions can also be reused across selected sites, with explicit provenance. Report the primary donor activation versus this supplementary control on all 36 pairs and on the existing 33-pair triple-competent subset. Reused rows are not independent measurements.

The supplement changes no activation site, intervention, primary denominator, source construction or validation decision rule. If it explains an apparent effect, that limits the claim regardless of whether an original development heuristic passes.

# Explanatory donor control panel

Implements the pre-final DEVELOPMENT-v1.md control commitment. First eight development program groups, fixed layer 26, both already declared boundaries, the development baseline stream 944001. This panel does not select sites or change final settings. Four paired source alternatives keep the recipient and random stream fixed: same z/different remaining operation parameter and answer; same z and answer/different first-step decomposition; different z/same donor answer; same-leading-digit value with an additional digit. Width and magnitude change together in the last condition.

Save every new source baseline; no source is chosen based on model success. Missing sites, incorrect source answers and recipient competence are explicit. Each alternative has both the original experiment's counterfactual and its own exact g_r(z_source). Report both, including all collisions. The 32 sources and 64 branches are repeated measurements from eight program groups. This is a development explanation check, not an independent final sample or population claim. Readable recovery examples and same-leading behavior do not identify a unique internal mechanism.

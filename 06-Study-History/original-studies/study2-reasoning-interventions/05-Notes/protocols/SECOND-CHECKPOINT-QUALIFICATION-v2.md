# CPU qualification after measured profile

CPU float32 native profiling cost 0.3267 seconds/token for 96 tokens and peak process RSS about 10.6 GiB (including loading). This supports a bounded qualification alongside GPU work, but makes a full six-site/64-group replication costly. Before these outputs, declare the first two existing *audit* groups, layers 13/20/26, both boundaries and 12 cached/recomputed steps per comparison. Require exact native/custom, no-op/identity token agreement and <=0.0005 full-vocabulary/cache and complete-candidate per-token score differences. Write locality must be exact, with positive source deltas. Full baselines retain 768 tokens and native EOS. The smaller audit depth is disclosed, not treated as identical coverage to Qwen3.

DeepSeek's native EOS string differs from Qwen3. Its parser adapter removes only that marker before applying the already tested answer grammar. No answer from a full second-checkpoint run was observed before this adapter was specified. The native thinking template already opens <think>; do not insert a second opening token.

If both audit groups have required sites and pass, a separately frozen small arithmetic replication can use the first four new pilot groups, both boundaries, fixed block 26, two streams, unchanged/activation/first-digit/full-value/random controls. This is an exploratory four-program scope check, not a powered second-model main study. Donor/supplied/recipient competence must each be at least 80% (therefore 4/4), with all failures retained. Do not reopen a failed gate by selecting other groups or tolerances. CPU/GPU, checkpoint architecture, training and size are confounded in any cross-model comparison.

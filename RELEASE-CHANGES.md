# Changes from the original project

This release was exported from the project folder in which the studies ran. Files are copied byte for byte except
those listed below. There are three kinds of change:

- **adapted:** code that names the two original study folders, which this release renames
  (`06-Study-History/original-studies/study1-value-transfer-and-readout` and `.../study2-reasoning-interventions`);
  code that read the environment files from another project folder (they are at the release root here); and the
  Study 5 verifier, whose freeze checks accept the changes this file documents. The reasons column says which.
- **redacted:** records in which personal or machine-specific strings were replaced: absolute paths and other
  projects' folder names by placeholders (`<project>`, `<portfolio>`, `<portfolio-root>`, `<workspace>`,
  `<research>`, `<environment-project>`, `<environment>`, `<sibling-project>`, `<other-project>`, `<other-area>`,
  `<study1-alias>`, `<coordination-folder>`, `<hf-cache>`, `<uv-data>`, `<home>`), the operating system's name by
  `[distro]`, cloud object ids by `[redacted]`, local timestamps by the same instant in UTC, and the names of the writing and coding tools in working records by the placeholder `[redacted]` (the assistants used are named in README.md, under "Use of AI assistants"). The renamed study folders are written with their new names
  everywhere. Nothing else in these files changed; the counts show how many strings of each kind were replaced.
- **not shipped:** files named in a freeze record but left out: model, tokeniser and kernel files (download
  them), logs, saved tensors, the original studies' written reports, review notes and briefs, code snapshots the
  original studies kept as history, and rendered figures.

Inputs larger than 1 MB are shipped compressed (`.xz`) and saved outputs as archives under `data/saved-outputs/`;
`tools/unpack.py` restores them byte for byte and checks each SHA-256 against `data/PACKED-FILES.json`.
Compression is not a change and is not listed below.

To check every freeze record against this release: `make check-freezes`.
